# AJI HUB

Lanceur d'applications HTML pour AJI Matériaux — Tout Faire.

🔗 **Accès :** https://greglp35.github.io/aji-hub/

## Applications disponibles

| App | Description |
|---|---|
| Cockpit Agence | Dashboard journalier — brief, actions, stock, livraisons |

## Ajouter une application

1. Déposer le fichier `.html` dans ce dépôt
2. Ouvrir le hub → `+ AJOUTER` → renseigner nom + URL complète
3. URL format : `https://greglp35.github.io/aji-hub/[fichier].html`

## Structure

```
aji-hub/
├── index.html              ← Hub principal
```
